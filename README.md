# tudu

Консольное приложение на Python для управления списком задач и работы с файлом `ToDo.txt`.

## ✨ Возможности

* **Добавление задач** — быстрое создание новых записей в списке с проверкой на пустой ввод.
* **Просмотр списка** — удобный вывод всех текущих задач в консоль.
* **Отметка о выполнении** — изменение статуса завершенных задач.
* **Простое хранение** — все данные сохраняются в локальном текстовом файле `ToDo.txt`.

---

## 📂 Структура проекта

```text
tudu/
├── tudu.py                    # Главный исполняемый файл (точка входа)
├── add_task.py                # Модуль добавления новой задачи
├── list_tasks.py              # Модуль вывода списка задач
├── done_task.py               # Модуль отметки задач как выполненных
├── version.py                 # Информация о версии приложения
├── AUTOGENERATED_VERSION.py   # Автоматически генерируемый номер версии
├── ToDo.txt                   # Файл для хранения списка задач
├── CHANGELOG.md               # Журнал изменений проекта
└── README.md                  # Документация проекта
```

## 📦 Сборка

Для сборки необходимо запустить файл `scripts/deploy.bat`.

При этом автоматически обновляется файл версии `AUTOGENERATED_VERSION.py` с помощью скрипта `scripts/version.py`.


Для упаковки в один файл используется **Nuitka**

Готовый исполняемый файл `tudu.exe` появится в папке `deploy/`.

*(Примечание: для работы программы рядом с `tudu.exe` должен находиться файл `ToDo.txt`, либо он будет создан автоматически при первом запуске).*

---

## 🚀 Примеры использования

* **Добавить новую задачу:**
  ```bash
  tudu.exe add "Купить продукты"
  ```

* **Посмотреть список задач:**
  ```bash
  tudu.exe list
  ```

* **Отметить задачу как выполненную:**
  ```bash
  tudu.exe done 1
  ```
